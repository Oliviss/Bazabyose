
# BAZABYOSE API

Backend API for BAZABYOSE Marketplace.

## Project Information

- Service Name: bazabyose-api
- Runtime: Node.js
- Framework: Express
- Database: Firebase Firestore
- Media Storage: Cloudinary

## Requirements

- Node.js 18 or higher
- Firebase Admin credentials
- Cloudinary account

## Installation

Run:

npm install

## Start Server

Run:

npm start

## Render Configuration

Service Name:
bazabyose-api

Root Directory:
backend

Build Command:
npm install

Start Command:
npm start

## Security

Never publish Firebase private keys or Cloudinary API secrets in GitHub.
Store secret credentials in Render Environment Variables.
